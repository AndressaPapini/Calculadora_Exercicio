## SOBRE O PROJETO

Este projeto foi desenvolvido como uma atividade prática para colocar em ação conceitos fundamentais de **React**, criando uma calculadora com uma interface simples, organizada e responsiva.

A aplicação permite realizar operações matemáticas de forma rápida por meio de uma interface visual desenvolvida especialmente para o exercício.

## APRENDIZADOS

Durante o desenvolvimento deste projeto foram praticados conceitos importantes de desenvolvimento front-end, principalmente:

* Estrutura de aplicações React
* Componentização
* Manipulação de estados
* Eventos em JavaScript
* Organização de interfaces
* Estilização com CSS
* Desenvolvimento de interfaces responsivas

---

## DIFERENCIAL DO PROJETO

A proposta não foi apenas criar uma calculadora funcional, mas também trabalhar a **organização visual da aplicação**, utilizando uma identidade em tons de rosa e uma interface limpa.

O projeto também serviu como exercício para compreender melhor como os componentes React se relacionam com a lógica da aplicação.
